Comparison of the Alpöge version and the Sernau versionAlpöge 版と Sernau 版の比較

Author: 著者：Sho Sonoda (RIKEN / CyberAgent) · sho.sonoda@riken.jp
This site is mainly generated by Anthropic Claude

Two Lean texts prove the same five theorems: the project distributed at alpo.ge (Alpöge version) and the much shorter text of the repository lsernau/grh-lean (Sernau version). We ran the same analysis of the proof network on both and put the results side by side: how large each is, which parts of Mathlib each uses, whether their lemmas coincide, which sub-theories each builds, and what the shortening does to the build and to the check.

同じ 5 つの定理を証明する Lean のテキストが 2 つある．alpo.ge で配布されているプロジェクト（Alpöge 版）と，リポジトリ lsernau/grh-lean のはるかに短いテキスト（Sernau 版）である．両方に同じ証明ネットワークの解析を行い，結果を並べた．それぞれの規模，Mathlib のどの部分を使うか，補題が一致するか，どんな部分理論を組み立てているか，短縮がビルドと検査に何をもたらすかを示す．

This is one of the pages of the report “Independent build report on Alpöge’s Lean formal proof of the Riemann Hypothesis”. Its scope, and the pointer to the statement of the Lean and Mathlib communities, are on the page Overview.

Summary要約

What is compared, and how何を，どのように比べたか

Alpöge version: the Lean project distributed at alpo.ge, the subject of the other pages. Sernau version: the repository lsernau/grh-lean, a shorter Lean text by other authors that proves the same five theorems (Shorter proof); it has a readable and a compact edition, and the compact edition is the main side of the comparison here. Both were compiled by us, and the same tools were run on both compiled results: the dependency graph of declarations, the use of the library, the sub-theories found in the graph, and the indicators of the page Proof analysis.

Alpöge 版：alpo.ge で配布されている Lean プロジェクト（他のページの対象）．Sernau 版：リポジトリ lsernau/grh-lean．別の作者による，同じ 5 つの定理を証明するより短い Lean のテキストである（短縮版）．可読版と圧縮版があり，ここでは圧縮版を比較の主な対象にする．どちらも我々がコンパイルし，その結果に同じ道具を適用した：宣言の依存グラフ，ライブラリの使い方，グラフから見つかる部分理論，ページ「証明の解析」の指標である．

The comparison is structural. It counts declarations, proof terms, library results and coinciding statements; it does not say which text is better, and, as everywhere in this report, it does not assess the mathematics. The two projects pin different versions of Lean and of Mathlib, which limits some comparisons (see Limits).

比較は構造についてのものである．宣言，証明項，ライブラリの結果，一致する言明を数える．どちらのテキストが優れているかは述べない．この報告の他の部分と同じく，数学的内容の評価も行わない．2 つのプロジェクトは Lean と Mathlib の版が違い，これが一部の比較を制限する（制約を参照）．

Do the statements coincide?言明は一致するか

For every theorem of the project that the five theorems depend on and that has a name of its own, we hashed its statement after replacing the project's own definitions by numbered placeholders. Two theorems then get the same hash exactly when their statements are the same expression up to a consistent renaming of project definitions; library declarations are compared by name. For the Alpöge version the hashes come from the tree of commit f1f6d654 of the community repository, which is the distributed tree with unreachable files removed and about twenty files edited (the same tree as for the indicators on Proof analysis).

5 つの定理が依存し，固有の名前を持つプロジェクトの定理のそれぞれについて，プロジェクト自身の定義を番号つきの仮の記号に置き換えたうえで，言明のハッシュを取った．2 つの定理のハッシュが一致するのは，プロジェクトの定義の名前を一貫して付け替えれば言明が同じ式になるときである．ライブラリの宣言は名前で比べる．Alpöge 版のハッシュは，コミュニティのリポジトリのコミット f1f6d654 のツリーから取った．これは配布時のツリーから届かないファイルを除き，約 20 ファイルを編集したもので，「証明の解析」の指標に用いたツリーと同じである．

Limits of the comparison比較の制約

  • Not a judgement. The page counts; it does not say that one text is a better proof than the other, and it does not assess the mathematics of either.評価ではない．このページは数えた結果を示す．どちらのテキストがよい証明かは述べないし，どちらの数学的内容も評価しない．
  • Different versions. The Alpöge version pins Lean v4.33.1, the Sernau version v4.35.0, each with its own revision of Mathlib. Library declarations are compared by name, so a renamed declaration counts as different; the page gives the number of names that do not exist on the other side. Build times are not for the same compiler.版の違い．Alpöge 版は Lean v4.33.1，Sernau 版は v4.35.0 を使い，Mathlib の版もそれぞれ違う．ライブラリの宣言は名前で比べるので，名前の変わった宣言は別のものと数える．相手側に存在しない名前の数はページに示した．ビルド時間は，同じコンパイラでの値ではない．
  • Coinciding statements are a lower bound. Only literally equal expressions are found, up to renaming of project definitions. Lemmas that express the same fact differently are not matched, and we did not try to match proofs or mathematical steps by hand.一致する言明の数は下限である．見つかるのは，プロジェクトの定義の名前の付け替えを除いて文字どおり等しい式だけである．同じ事実を別の形で述べた補題は対応づけられない．証明や数学的な段階を人の手で対応づけることもしていない．
